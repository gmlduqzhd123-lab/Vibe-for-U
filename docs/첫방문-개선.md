# 처음 쓰는 학생과 교사를 위한 10가지 개선

## 화면에서 찾는 방법

| 제안 | 구현한 동작 |
|---|---|
| 앱을 설명하는 한 문장 | 홈 첫 화면에 퀴즈·이야기·타이머를 만들고 고치며 배우는 앱이라고 표시 |
| 학생과 교사 입구 | 학생 체험하기 → `/explore`, 교사 수업 준비 → `/prepare` |
| 완성 예제 체험 | 홈과 학생 체험 화면에서 퀴즈·두 갈림길·5초 타이머를 실제 실행 |
| 3분 첫 체험 | `/try`에서 예상 선택, 같은 정답 세 번, 3점 오류 관찰, 한 번 채점으로 수정, 같은 검사로 1점 확인 |
| 그림으로 보는 과정 | 다섯 단계의 실제 작업실 예시 이미지와 학생 말풍선. 이미지를 누르면 큰 화면으로 확인 |
| 쉬운 용어 | 홈·체험·교사 준비·작업실에 요청문·검사·버그·상태·버전·포트폴리오 풀이. 버전 패널에도 설명 |
| 교과 연결 | 과학 퀴즈·국어 이야기·체육 타이머 수업 아이디어와 해당 미션으로 이동 |
| 내일 바로 하는 40분 | 홈의 1차시 준비 카드, 교사 준비 화면의 8차시 선택·목표·준비물·5/30/5분 흐름·활동지·안내서 |
| 고치기 전후 비교 | 같은 정답 세 번에 기존 퀴즈 실행기를 사용해 3점과 1점을 나란히 비교하고 수정 이유 설명 |
| QR과 소개 문구 | `/share`에서 전체 앱·3분 체험·8차시 QR 카드 10종을 선택, PNG 저장·한 장 인쇄·소개 문구와 주소 복사 |

## 상태와 저장

완성 예제와 3분 체험은 임시 화면 상태만 사용합니다. 가입이나 새 작품 저장을 먼저 요구하지 않습니다. 3분 체험에서 고친 규칙으로 내 작품 만들기를 누르면 정상 규칙의 새 작품을 만들고 학생이 고른 예상과 직접 쓴 수정 이유를 옮깁니다. 새 작품의 실행·검사 완료는 자동으로 표시하지 않으며 직접 다시 해야 합니다. 잘못된 예상도 학생이 고른 그대로 보존합니다.

3분은 활동 분량 안내이며 시간 제한이 아닙니다. 단계와 완료 결과가 바뀔 때 해당 제목으로 키보드 초점과 스크롤을 이동합니다. 규칙을 다시 바꾸면 현재 실행과 횟수를 초기화하고 수정 완료 표시를 해제합니다.

기존 미션 12개, 작품 선반, 버전·포트폴리오·백업 및 교사 자료실은 계속 사용할 수 있습니다. 안내 모드와 학생·교사 입구는 접근 권한이나 계정 인증이 아닙니다.

## QR 카드

QR은 공개 주소와 차시 번호만 담으며 학생 작품이나 입력 내용을 넣지 않습니다. 외부 QR 생성 서비스는 사용하지 않습니다. `src/qrData.ts`에 미리 만든 QR 경로를 보관하고 소개 카드 화면을 열 때 별도 JavaScript 파일로 불러옵니다. PNG는 브라우저에서 카드 SVG를 직접 그려 생성합니다. 다운로드 성공을 단정하지 않고 브라우저 다운로드 목록 확인을 안내합니다. 복사가 거절되면 기존 직접 선택 대화상자를 사용합니다.

배포 주소를 바꿀 때는 `scripts/generate-qr.py`의 공개 주소를 고치고 ReportLab이 있는 Python으로 실행한 뒤 생성 파일을 포맷하고 QR 판독을 재검사합니다. npm 실행·빌드에는 Python이 필요하지 않습니다.

## 검증 시나리오

`tests/onboarding.spec.ts`는 예제 실행과 무저장, 3분 체험과 기록 이전, 교사 수업 준비, 10개 QR 화면·PNG 다운로드·복사 실패 대안·인쇄, 360/768/1440px의 여섯 화면 접근성을 검사합니다. 기존 `tests/e2e.spec.ts`의 학습·저장 흐름과 함께 실행합니다. QR은 화면 캡처와 실제 다운로드 PNG를 별도의 판독기로 확인합니다.

이 검사는 Edge의 화면 크기 에뮬레이션과 소프트웨어 QR 판독입니다. 실제 휴대전화 카메라·학교 기기·물리 프린터·교사 수업 운영을 대신하지 않습니다.

로컬 실행 결과는 핵심 테스트 22개 및 전체 브라우저 시나리오 24개 통과입니다. 새 화면 여섯 종류를 각각 360/768/1440px로 검사해 가로 넘침과 axe WCAG A·AA 위반이 없었습니다. QR 10종의 화면 캡처와 실제 저장된 PNG를 별도 ZXing 판독기로 확인했습니다. A4 인쇄 PDF는 한 쪽이며 렌더 이미지의 QR도 올바르게 판독됐습니다.

차시별 QR은 `/lesson/1`부터 `/lesson/8`까지 각 차시 학생 안내로 연결됩니다. 같은 퀴즈 미션을 쓰는 차시도 목표·진행·활동지를 구별해 보여 줍니다. 2·7차시는 지난 작품 이어하기를, 6차시는 외부 AI 교사 조작 안내를 함께 제공합니다.
