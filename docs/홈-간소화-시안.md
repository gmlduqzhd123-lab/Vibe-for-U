# 홈 화면 간소화 비교 시안

이전 첫 방문 홈의 본문에는 9개 구역과 25개 버튼이 있어 소개·체험·학습 과정·수업 준비·자료·공유가 경쟁했습니다. 사용자가 첫 행동을 정하기 쉽게 정보 구조가 서로 다른 시안 3종을 제안했고, 사용자가 선택한 **1안 역할 선택형을 실제 홈에 채택했습니다.**

비교 페이지는 `concepts/index.html`, 각 독립 시안은 `concepts/a.html`, `concepts/b.html`, `concepts/c.html`입니다. 첫 화면의 주요 선택은 각각 2개, 1개, 3개입니다.

| 시안 | 첫 선택 | 시작 흐름 | 적합한 상황 |
|---|---|---|---|
| 1안 역할 선택형 | 학생으로 시작 / 교사로 시작 | 학생은 3분 체험, 교사는 수업 준비 | 학생과 교사가 함께 쓰는 기본 홈 |
| 2안 체험 집중형 | 3분 체험 시작 | 짧은 체험으로 앱의 목적 이해 | 처음 사용하는 학생에게 안내 |
| 3안 작품 선택형 | 퀴즈 / 갈림길 이야기 / 타이머 | 해당 작품의 미션 안내 | 만들고 싶은 작품이 있는 사용자 |

세 안 모두 사이드바와 본문의 상세 기능 나열을 상단 전체 메뉴로 모았습니다. 전체 미션, 내 작품, 교사 자료, QR 카드는 메뉴에서 실제 앱으로 연결됩니다. 역할 선택은 계정이나 권한 설정이 아닙니다. 비교 화면에서 PC·모바일 너비를 바꿔 볼 수 있습니다.

기존 색상과 SVG 캐릭터를 재사용했습니다. 제목과 로고 끝에는 온점을 붙이지 않았습니다. 설명이나 예제 그림은 선택에 필요한 만큼만 남기고, 실제 학습과 수업 자료는 연결된 다음 화면에서 확인합니다.

`concepts/`의 페이지들은 비교 기록으로 남긴 독립 시안입니다. 실제 홈은 React의 `RoleHome.tsx`와 홈에서만 적용되는 `RoleHome.css`로 구현했습니다. 학생은 3분 체험으로, 교사는 수업 준비로 이동합니다. 최근 작품 이어하기는 실제 저장된 최근 작품과 연결합니다. 전체 메뉴에는 기존 기능과 안내 모드를 제공하고, 키보드 Esc·바깥 클릭으로 접을 수 있습니다. 원래 학습 화면의 탐색 메뉴는 계속 사용합니다.

핵심 테스트 22개와 전체 브라우저 흐름 25개가 로컬에서 통과했습니다. 이 검사에는 전체 메뉴 키보드 조작, 안내 모드 저장과 새로고침, 기존 작품 이어하기, 공용 기기 목록, 작품·백업 보존, 세 가지 화면 너비와 접근성이 포함됩니다. 추가로 1360×860, 390×844, 360×844 화면을 직접 확인했습니다.

로컬에서 각 시안의 1360×860 및 390×844 화면, 가로 넘침, 첫 시작 링크 위치, axe WCAG A·AA, 메뉴 열기·Esc 닫기, 6개 시작 링크의 실제 도착 화면, 비교 페이지의 3안 전환과 모바일 너비 전환을 확인했습니다. 기본 앱의 프로덕션 빌드도 성공했습니다.
