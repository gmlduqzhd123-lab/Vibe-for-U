# 실기기 점검표

자동 검사(CI)는 GitHub 러너의 Microsoft Edge·Chromium·WebKit에서 같은 흐름을 확인합니다. WebKit은 Safari와 같은 엔진이지만 Safari 앱 자체가 아니고, 러너는 실제 학교 기기·휴대전화·프로젝터·프린터가 아닙니다. 아래 항목은 수업 전에 **실제 기기에서 교사가 직접** 확인하는 목록입니다. 결과는 맨 아래 기록표에 남겨 다음 학기에 다시 씁니다.

## 자동 검사가 맡는 범위

| 범위 | 자동 검사 | 실기기에서 더 볼 것 |
|---|---|---|
| 화면 크기 | 360·768·1440px 가로 넘침, axe WCAG 2.1 AA | 실제 글자 크기 설정(큰 글씨)·확대 200% |
| 저장 | IndexedDB 저장·새로고침·탭 잠금·저장 실패 복구 | 학교 기기 관리 정책(브라우저 데이터 자동 삭제, 시크릿 창 강제) |
| 오프라인 | 서비스 워커 캐시 후 오프라인 열기 | 학교 와이파이가 끊긴 상태에서 실제로 다시 열기 |
| 소리 | 신호음 횟수(가짜 오디오), 읽어 주기 버튼 상태(가짜 음성) | 실제 스피커 음량, 기기에 설치된 한국어·영어 음성 |
| 파일 | 내려받기·가져오기·공유 창(가짜 공유) | 실제 다운로드 폴더 위치, 메신저·드라이브로 보내고 다른 기기에서 열기 |
| 인쇄 | 인쇄 화면에서 숨길 영역 | 실제 프린터의 여백·양면 인쇄 |

## 기기별 점검 항목

각 기기에서 [공개 주소](https://gmlduqzhd123-lab.github.io/Vibe-for-U/)를 열고 차례로 확인합니다.

### 공통 (모든 기기)

- [ ] 첫 화면이 10초 안에 열리고, **학생 체험하기 → 3분 첫 체험**을 끝까지 할 수 있다.
- [ ] 미션 하나를 시작해 제목을 적고 새로고침해도 남아 있다(기기에 저장됨 표시).
- [ ] 와이파이를 끄고 다시 열어도 앱과 작품이 열린다(한 번 연 기기).
- [ ] **작품 선반 → 목록 백업**으로 파일이 내려받아지고, 그 파일을 **파일 가져오기**로 다시 열 수 있다.
- [ ] **기록 보존 상태**에서 보존 요청을 눌렀을 때 결과 안내가 나온다(지원하는 브라우저만 패널이 보임).
- [ ] 쉬운 모드에서 **읽어 주기**를 눌러 소리가 난다. 영어 화면에서는 영어 음성으로 읽는다.
- [ ] 같은 작품을 탭 두 개로 열면 한 탭만 편집되고 다른 탭은 읽기 전용이다.

### 학교 PC (Windows · Edge / 크롬 / 웨일)

- [ ] 학교 계정 로그인 상태와 로그아웃 상태에서 각각 저장이 유지되는지(로그아웃 시 브라우저 데이터를 지우는 정책 확인)
- [ ] 수업 자료 PDF가 새 탭에서 열리고 Word 수정본이 내려받아진다.
- [ ] 포트폴리오 **인쇄 / PDF 저장**이 실제 프린터에서 잘리지 않는다.

### 태블릿 (iPad Safari · 안드로이드 크롬 · 크롬북)

- [ ] 가로·세로를 돌려도 작업실 단계 버튼과 실행 화면이 가려지지 않는다.
- [ ] **공유로 보내기**로 작품 파일을 메신저·드라이브에 보낼 수 있다.
- [ ] 홈 화면에 추가한 뒤 앱처럼 열리고, 저장한 작품이 그대로다.
- [ ] (iPad) 7일 넘게 열지 않으면 Safari가 저장소를 지울 수 있으므로, 보존 요청과 파일 백업 안내를 학생에게 전했다.

### 휴대전화 (아이폰 Safari · 안드로이드 크롬)

- [ ] 360px 정도의 좁은 화면에서 글 입력 칸이 키보드에 가려지지 않는다.
- [ ] 친구 검사 요청 파일을 받아 **파일 가져오기**로 열고, 결과 파일을 돌려보낼 수 있다.

### 교사 기기 + 프로젝터

- [ ] **수업 진행 화면**을 프로젝터에 띄워 맨 뒷자리에서 글자가 읽힌다.
- [ ] **전체 화면**이 되거나, 지원하지 않는 기기에서는 넓게 쓰는 방법 안내가 보인다.
- [ ] **소리로도 알리기**를 켜고 시작했을 때 교실 스피커로 교대(두 번)·종료(세 번) 신호음이 들린다.
- [ ] 학급 작품 모으기에 학생 파일 여러 개를 한꺼번에 넣고, 새로고침해도 목록이 이어서 열린다.
