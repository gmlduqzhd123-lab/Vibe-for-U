# 교사 안내서와 차시별 학생 활동지 연결

2026년 10월 25일 작성한 수업 자료를 교사 자료실에 연결했습니다.

## 사용할 곳

- 교사 자료실의 8차시 수업 안내 상단: 교사용 안내서 14쪽, 학생 활동지 합본 16쪽의 PDF 열기·내려받기와 Word 수정본
- 모두 받기: 위 네 파일, 차시별 PDF 8개, 인쇄 안내 1개를 담은 ZIP
- 각 차시 미션 안내 아래: 해당 차시의 앞뒤 2쪽 활동지 PDF 열기·내려받기
- 화면 안내 인쇄: 웹 화면 인쇄이며 파일 받기 영역은 출력에서 제외

`public/materials/`의 파일은 빌드 결과에 함께 복사됩니다. 학생 계정이나 외부 문서 서비스를 추가하지 않았으며 문서를 선택할 때만 해당 파일을 요청합니다.

## 실행한 로컬 검사

- 핵심 테스트 22개 통과, TypeScript 검사 및 프로덕션 빌드 성공
- 실제 Edge 기존 학습·저장·접근성 흐름 19개 통과
- `/pages-check/` 하위 경로에서 자료 14개 요청 HTTP 200 및 원본 SHA-256 일치
- UI 링크로 PDF·Word·ZIP 총 13개 실제 다운로드 후 원본 SHA-256 일치
- ZIP 내부 13개 항목 무결성 확인
- 교사 자료실 360·768·1440px에서 가로 넘침 없음, axe WCAG A·AA 위반 없음
- 인쇄 모드에서 다운로드 영역 숨김 확인
- 차시별 PDF 8개가 각각 2쪽이며 합본의 해당 쪽과 본문이 일치
- 분리한 PDF 16쪽을 110 DPI로 다시 렌더링한 이미지가 앞서 전체 검토한 합본 이미지와 픽셀 단위로 일치
- PC·태블릿·휴대전화 크기의 화면 이미지를 직접 확인

이 문서의 검사는 로컬 빌드와 설치된 Edge의 화면 크기 에뮬레이션입니다. 공개 배포 후에도 같은 다운로드·응답·접근성 검사를 실행해 공개 파일이 이 소스의 파일과 일치하는지 별도로 확인합니다. 물리 프린터나 실제 학교 기기에서 수업한 증거를 뜻하지 않습니다.

## 2026-10-30 추가: 새 기능 수업 보충 안내

- `public/materials/new-features-guide.pdf`·`.docx`(4쪽): 안내서 이후 더한 패턴 그리기·쉬운 모드·친구 검사·자기 평가·수업 진행 화면·되돌리기·영어 화면·공용 기기 주의와 친구 검사 기록지 1쪽
- 교사 자료실 **수업 자료 내려받기**에 세 번째 카드로 연결하고, 모두 받기 ZIP에 `새_기능_수업_보충_안내.pdf`·`.docx`를 더함(ZIP 15개 항목, 무결성 검사 통과). `먼저_읽어주세요.txt`에도 설명을 더함
- 만들기: `python3 scripts/make-supplement.py` 뒤 `soffice --headless --convert-to pdf`로 PDF 변환. 본문 글꼴은 맑은 고딕으로 지정했고, 변환한 Linux 환경에는 맑은 고딕이 없어 PDF에는 WenQuanYi Zen Hei가 들어감
- 검사: `tests/materials.test.ts`가 자료 카드마다 PDF·Word가 있고 ZIP에 보충 안내가 들어 있는지 확인. 4쪽을 이미지로 렌더링해 표 너비·기록 칸 크기를 직접 확인함. 실제 프린터 출력은 확인하지 않음
